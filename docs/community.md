# Community integrations

- OpenSea displays OpenRarity rankings for eligible collections.
  [OpenSea Help Center](https://support.opensea.io/en/articles/8867099-what-is-openrarity)
- `open-rarity-core` is an independent TypeScript port covering categorical
  scoring through its own API. Its repository documents the supported inputs.
  This project has not verified the port against the 1.0 conformance suite.
  [Community port source](https://github.com/oswaldb22/open-rarity-core)
